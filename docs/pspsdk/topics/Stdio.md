# Stdio Library

This module contains the imports for the kernel's stdio routines.

## Functions

- [`sceKernelStdin()`](../files/user/pspstdio.h.md#scekernelstdin) – Function to get the current standard in file no.
- [`sceKernelStdout()`](../files/user/pspstdio.h.md#scekernelstdout) – Function to get the current standard out file no.
- [`sceKernelStderr()`](../files/user/pspstdio.h.md#scekernelstderr) – Function to get the current standard err file no.
