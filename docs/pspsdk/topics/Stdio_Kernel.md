# Driver interface to Stdio

This module contains the imports for the kernel's stdio routines.

Headers: [`kernel/pspstdio_kernel.h`](../files/kernel/pspstdio_kernel.h.md)

## Functions

- [`sceKernelStdoutReopen()`](../files/kernel/pspstdio_kernel.h.md#scekernelstdoutreopen) – Function reopen the stdout file handle to a new file.
- [`sceKernelStderrReopen()`](../files/kernel/pspstdio_kernel.h.md#scekernelstderrreopen) – Function reopen the stderr file handle to a new file.
- [`fdprintf()`](../files/kernel/pspstdio_kernel.h.md#fdprintf) – fprintf but for file descriptors
